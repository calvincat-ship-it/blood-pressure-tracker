# 血壓記錄 App

純前端網頁 App（PWA），可記錄每日血壓／心跳，具備：新增、編輯、刪除紀錄、清除全部紀錄、拍照附加紀錄、趨勢折線圖、依血壓標準自動分級（正常／偏高／第一期／第二期／危象）、近 7 天平均、CSV 匯出、分享（透過 LINE／Email 等 App 分享）、定期寄送提醒。紀錄資料存在手機瀏覽器的 localStorage，照片存在瀏覽器的 IndexedDB，都不需要網路或帳號。

## 拍照附加紀錄

「新增紀錄」卡片裡的「📷 拍攝照片」按鈕，會呼叫手機相機（`<input type="file" capture="environment">`），第一次使用時 Android 會照標準流程跳出相機權限請求，之後就不會再問。拍完的照片會自動壓縮後存進瀏覽器的 IndexedDB，紀錄本身只存照片的參考 ID。歷史紀錄清單不會直接顯示照片縮圖，只有在該筆紀錄有照片時才會多一個「🖼 檢視」按鈕，點下去用全螢幕檢視。刪除單筆紀錄、清除全部紀錄、或寄送後自動清除，都會一併刪除對應的照片，不會留下孤兒資料。

## 分享與定期寄送提醒

- **分享**（標題列 📤）：呼叫手機的原生分享選單，可分享到 LINE、Email 等已安裝的 App（支援檔案分享的瀏覽器會一併附上 CSV）。
- **設定**（標題列 ⚙）第一區：設定收件 Email、寄送頻率（每週／每月／固定天數）、以及「傳送完成後自動清除舊紀錄」。

## 量測提醒通知

**設定**（標題列 ⚙）第二區可以設定每天最多 3 個時間點，到點時跳出通知提醒該量血壓了。第一次啟用時瀏覽器會跳出「允許通知」的權限請求。

**限制**：跟寄送 Email 提醒一樣，這是純前端網頁，沒有背景常駐服務，所以無法在「App 完全關閉」時準時跳出通知——這是瀏覽器安全機制的限制。實際運作方式是：只要這個分頁/App 有開著（即使切到背景分頁也算），程式每 20 秒會檢查一次目前時間，時間到就跳出系統通知（沒有通知權限則改用畫面內提示）；如果 App 完全關閉，就不會收到那次提醒。若要做到「手機完全不開這個 App 也會準時通知」，需要額外的伺服器（透過 Web Push 排程發送），目前未實作。

**限制**：這是純前端的靜態網頁，沒有伺服器，所以無法在「App 沒有被打開」的情況下自己在背景寄信。實際運作方式是「半自動」：當你打開 App 時，如果已經到了設定的寄送週期，畫面上方會出現提醒卡片，點「立即寄送」會開啟手機預設的郵件 App 並帶入收件人、主旨、內容，你只需要按一下寄送；回到 App 後會問你「郵件是否已經寄出」，回答「是」才會更新寄送時間（並依設定清除舊紀錄）。若要做到完全不開 App 也能自動寄信，需要額外的雲端後端服務（資料同步、排程、寄信 API），目前未實作。

## 高血壓服藥提醒

**設定**（標題列 ⚙）第三區可以啟用「每日第一次出現高血壓紀錄時提醒服藥」。判定方式可選：
- **自動**：沿用 App 內建的血壓分級標準，達到「第一期高血壓」以上（收縮壓 ≥130 或舒張壓 ≥80）就算過高。
- **自行設定門檻**：自訂收縮壓／舒張壓的門檻數值。

只要當天新增或編輯的紀錄符合門檻，且當天先前還沒有其他紀錄也符合門檻，就會立刻跳出提醒視窗「目前您的血壓有過高的情況，請記得服藥以控制血壓」；同一天內後續再出現的高血壓紀錄不會重複提醒。

## 本機測試（在電腦上）

```
node serve.js
```

再用瀏覽器開啟 http://localhost:5173

## 安裝到 Android 手機

Service Worker（離線快取＋「加入主畫面」安裝功能）只有在 **https** 或 **localhost** 才會啟用，所以要讓手機真正「安裝」這個 App，需要把這個資料夾放到一個網址上，例如：

1. **GitHub Pages / Netlify / Vercel**：把 `blood-pressure-tracker` 資料夾內容部署上去（皆有免費方案），取得一個 https 網址。
2. 用手機 Chrome 開啟該網址。
3. 點右上角「⋮」選單 →「新增至主畫面」或「安裝應用程式」。
4. 之後就會像一般 App 一樣有圖示，可離線使用、資料留在手機本機。

若只是想在同一個 Wi-Fi 下用手機瀏覽器直接使用（不需要真的「安裝」），也可以：
1. 在電腦上執行 `node serve.js`。
2. 查詢電腦的區網 IP（例如 `ipconfig` 看到的 192.168.x.x）。
3. 手機瀏覽器開啟 `http://192.168.x.x:5173`，即可使用（此模式無法安裝為獨立 App，也無離線快取）。

## 檔案結構

- `index.html` / `style.css` / `app.js`：主程式
- `manifest.json` / `sw.js`：PWA 安裝與離線快取設定
- `icons/`：App 圖示
- `serve.js`：本機測試用的簡易伺服器
